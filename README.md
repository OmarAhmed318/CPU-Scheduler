# CPU Scheduler

\# CPU Scheduler



A CPU scheduling simulator built with C++ and Qt, supporting multiple scheduling algorithms with both static and live execution modes.



\## Features



\- \*\*FCFS\*\* – First Come First Serve

\- \*\*SJF\*\* – Shortest Job First (Preemptive \& Non-Preemptive)

\- \*\*Priority Scheduling\*\* (Preemptive \& Non-Preemptive)

\- \*\*Round Robin\*\* – with configurable quantum



\## Modes



\- \*\*Static\*\* – Run all processes at once and see the full Gantt chart

\- \*\*Live\*\* – Watch the scheduler run tick by tick in real time



\## How to Run



1\. Open the project in \*\*Qt Creator\*\*

2\. Build and run using \*\*MinGW 64-bit\*\* kit

3\. Select a scheduling algorithm, enter your processes, and hit Submit



\## Built With



\- C++

\- Qt 6.11 (Widgets, GUI)
